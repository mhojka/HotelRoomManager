# HotelRoomManager.Api

## Running the HotelRoomManager API
To run the Hotel Room Manager API, use the following command:
```bash
dotnet run --project .\HotelRoomManager.Api\
```
By default, the API will be available at http://localhost:5039

## Hotel Room Manager Testing Instructions
### Integration Tests
To run integration tests, use the following command:
```bash
dotnet test .\HotelRoomManager.IntegrationTests\
```
### Unit Tests
To run unit tests, use the following command:
```bash
dotnet test .\HotelRoomManager.UnitTests\
```
